# Pierre Laurent — Product Lab

Site personnel de Pierre Laurent, product builder et créateur de ProbaLab et
Ferdinand.

## Positionnement

Ce dépôt n'est plus un site de prestations. Il présente des produits numériques
personnels et la méthode qui les relie : systèmes de données, applications web,
expériences mobiles et automatisations fiables.

## Stack

- Next.js 16 / React 19 / TypeScript
- CSS Modules et variables CSS
- Vercel Analytics
- déploiement Vercel sur `www.opti-pro.fr`

Le site public est statique et ne dépend plus de Supabase, Resend ou d'un
back-office.

## Commandes

```bash
npm run typecheck
npm run lint
npm test
```

`npm run build` et tout déploiement nécessitent l'autorisation explicite de
Pierre avant exécution.
